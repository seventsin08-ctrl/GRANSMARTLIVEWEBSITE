# GrainSmart — source export for GitHub

This folder contains all 146 tracked files from GrainSmart version 55.

## Upload to GitHub
1. Extract this ZIP.
2. Create your GitHub repository.
3. Upload the contents of the grainsmart folder, including dotfiles (.gitignore, .npmrc, and .openai).

## Run locally
Use Node.js 22.13.0 or newer. From this folder run:

```sh
npm run install:ci
npm run dev
```

See the original README.md for development, builds, and local database setup.

## Hosting
This is a full-stack React/Vinext application using Cloudflare Workers, D1 (DB), and R2 (BUCKET). GitHub can store the source; GitHub Pages alone cannot run the APIs, ordering, admin, and database features. Independent deployment requires configuring those services and replacing platform-specific hosting and authentication settings. The .openai/hosting.json file identifies the original ChatGPT Site.

Runtime secrets such as ADMIN_PASSWORD_HASH and ADMIN_SESSION_SECRET must be configured separately on the backend host. Production database records, orders, customer information, uploaded R2 files, and runtime secrets are not part of this source export. Image URLs in the code continue to reference their existing hosts.

The original source files are unchanged. This export adds only this guide. Dependencies and build outputs are generated by installation and build commands and are not included.
